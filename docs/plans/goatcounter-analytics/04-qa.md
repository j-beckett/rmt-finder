# Manual QA on production

**Type:** HITL

## Parent PRD

`docs/prd/goatcounter-analytics.md`

## What to build

Nothing new. The owner verifies on production that the whole feature works
end to end and the numbers are clean. Run this after slices 01–03 are deployed
and the server from slice 02 is live. Wait a few seconds and refresh the
dashboard between actions, because GoatCounter saves hits in batches.

## Acceptance criteria

**Server**

- [ ] `https://stats.studiobeckett.ca` loads with a valid certificate and asks for login
- [ ] Logged out, a private window cannot see any stats
- [ ] `https://rmtfinder.studiobeckett.ca` still loads and shows slots
- [ ] `free -m` on the droplet still shows healthy available memory; the
      GoatCounter service shows its memory cap

**Data path**

- [ ] `/api/availability?city=victoria` slots include `clinic_slug`, and the
      values match the approved list

**Opt-out (normal browser)**

- [ ] Visit `/?notrack` on each owner device (laptop, phone, any others)
- [ ] In an opted-out browser: load the site, switch city, click a Book card.
      **No** new hits appear on the dashboard
- [ ] `?notrack=off` turns tracking back on, and `/?notrack` turns it off again

**Tracking (incognito/private window)**

- [ ] Load `/` with no `?city=`: a view appears under the default city's
      path (e.g. `/victoria`), not `/`
- [ ] Load `/?city=langford&utm_source=test&fbclid=abc`: the view appears
      under `/langford` (no params in the path), and `test` shows as a campaign
- [ ] Switch city with the menu: a view for the new city appears
- [ ] Press Back: a view for the previous city appears
- [ ] Load `/?city=nowhere`: a view appears under `/unknown-city` with
      `nowhere` in the title
- [ ] Left-click a slot card: `book/<slug>` appears with the clinic name as
      title, and the booking page opened in a new tab immediately
- [ ] Middle-click a slot card: another `book/<slug>` hit appears
- [ ] Tap a slot card on a phone (incognito): a `book/<slug>` hit appears
- [ ] Right-click → "Open in new tab": no hit (expected, documented undercount)

**Dashboard views**

- [ ] Filtering paths by `book/` narrows the browser/system/size panels to Book clicks
- [ ] Filtering by `equilibrium` shows all Equilibrium locations together
- [ ] Referrers panel lists a referrer for a visit that came via a link
- [ ] Creating a view-only secret link works in a logged-out window, and
      revoking it stops access

**Resilience and docs**

- [ ] With an ad blocker blocking `stats.studiobeckett.ca`, the site and Book
      links work normally, with no console errors from tracking
- [ ] README "How it works" diagram renders on GitHub and matches what is tracked
- [ ] Record a baseline for the "what looks wrong" check: note this week's
      typical daily views and top referrers
